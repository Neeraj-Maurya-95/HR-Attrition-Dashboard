# HR-Attrition-Dashboard
HR Attrition Analysis Dashboard using Excel and Power 

# Project Overview
This project focuses on analyzing employee attrition using Microsoft Excel and Power BI.

The objective of this project is to analyze employee demographics, job roles,
departments, salary, experience, job satisfaction and attrition patterns
through an interactive Power BI dashboard.

## Power Query
Power Query was used to prepare the dataset for Power BI.

Transformations included:

- Changing data types
- Removing duplicates
- Handling missing values
- Renaming columns
- Creating calculated columns
- Splitting and merging columns
- Data transformation

# DAX
DAX was used to create important HR metrics such as:

- Total Employees
- Attrition Count
- Attrition Rate
- Active Employees
- Average Salary
- Average Age
- Average Tenure

# Dashboard Features
The Power BI dashboard provides analysis based on:

- Department
- Job Role
- Gender
- Age Group
- Education
- Salary
- Job Satisfaction
- Years at Company
- Attrition

# Key Insights
The dashboard helps HR teams identify:

- Departments with higher attrition
- Job roles with higher employee turnover
- Employee demographic patterns
- Salary-related attrition patterns
- Experience and tenure patterns
- Employee satisfaction trends
